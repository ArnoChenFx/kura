# 翻译、浏览与历史恢复

本轮任务记录在 [Issue #13](https://github.com/ArnoChenFx/kura/issues/13)，基于 MyGo v0.5.5，不新增快捷键或依赖，不修改用户上传的截图。

## 翻译服务与迁移

`settings.json` 新增 `provider`，支持 `google`、`microsoft`、`openai`。新用户或完全空的配置默认 Google；没有 provider 但含任一旧自定义字段的配置继续使用 OpenAI，包括未填写完整的配置。未知服务或损坏配置不自动转发给免费服务。设置中的免费服务与自定义 API 可以切换，隐藏的自定义字段仍保留；只有开启译文才请求。

Google 使用公开匿名翻译接口。微软使用 Bing 翻译网页的匿名会话，临时令牌与 Cookie 仅用于该次调用，不落盘。两个适配器固定服务域名，限制请求与响应大小，尊重取消，不跟随重定向，不把旧 API 密钥或原文放进错误提示；失败不跨服务重试。Markdown 的代码、链接目标、frontmatter、换行与格式标记由占位符保护，标记丢失、增加或重排时拒绝该份译文。

Google 已使用自编短文与 2,832 字节 Markdown 验证成功，后者两次请求并保留全部受保护结构。微软的匿名页面返回 200，但本云环境的实际翻译请求返回 401；公开 Edge auth 入口也返回 404。微软适配完成离线协议与取消/隐私测试，但本轮不能宣称其实网翻译可用，仍需可访问地区的后续验证。服务拒绝时界面保留原文并允许重试或切换。

全文缓存判断在分段之前，分段放到后台。每份文档有独立取消上下文与任务序号；停止或失败保留已完成段落，继续只请求剩余部分。服务、语言或原文变化会使旧结果失效。缓存与进度只在内存；本地源码读取先限制为 512 KiB，再显示截断提示。

发布前组合审查修复了分段丢失保护上下文的问题：先按完整文档的保护区判断分界，列表围栏、原始 HTML、注释、frontmatter 与跨行代码不会在空行处拆开。独立缩进代码不误开新围栏或 HTML 状态，列表围栏按其容器缩进闭合。回归实际串联分段、服务派发与模拟 HTTP，确认受保护内容不进入请求、普通正文仍可翻译；store 与 UI 定向 race 通过。v0.1.14 将微软服务标为实验性，保留上述实网限制。

## 目录与批量更新

每个根目录保存本次会话的查询、筛选、选中名称与状态，以及独立 MyGo 网格/列表滚动状态。扫描成功后才验证恢复的选择；扫描失败保留待验证身份，同名不同状态不能替代已删除的原副本。来源仓库和本地路径加入原有搜索索引。

批量评审按技能勾选，本地修改默认不选。应用后保留逐项结果，成功项不能再次应用旧预览，重试只操作选中的失败项。检查、更新与恢复沿用根目录代次保护；写入通过根目录与技能名组成的忙碌状态互斥，切换目录后也释放原任务的占用。

## 历史恢复

历史面板列出快照时间与差异，支持有界逐行文本预览。恢复计划绑定原根目录、技能名称、启用/停用状态、快照及两侧内容指纹，包含元数据；执行前重新验证。无元数据的本地技能可以恢复，损坏历史元数据、越界路径、符号链接与特殊文件被拒绝。

恢复先准备同盘临时副本并保存当前版本，再通过重命名替换；失败尝试回滚，保留当前内容与恢复前快照。同名的其他状态或其他根目录不会成为恢复目标。文件与目录互换、元数据变化、可执行权限、过期预览、替换失败和旧目录回调均有回归覆盖。

## 界面验证边界

离线测试使用临时技能目录与模拟翻译服务，不触碰真实技能数据。原生 Linux 窗口检查使用无网络容器与隔离数据，覆盖深浅主题、1,200×760 和 880×520 的设置与历史面板；临时截图只用于检查，不更新仓库截图。Windows/macOS 原生窗口与各地区免费服务连通性不能由本次 Linux 检查替代。

完整 `go test ./...`、无 CGO 测试/构建、Go vet、MyGo vet 与 505 条双语文案检查通过；UI/store 全量 race 通过（UI 276.376 s，store 17.192 s），最后新增接线另有定向 race 覆盖。Windows amd64 桌面应用与 NSIS 安装器构建通过。
