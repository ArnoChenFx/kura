# 滚动、内容空间与长列表

本轮基于 MyGo v0.5.5，不新增快捷键或依赖。

## 滚动与布局

鼠标离散滚轮位移缩为原来的 45%，用 140 ms EaseOut 过渡。连续同向输入累积目标，
反向从当前可见位置转向；触控板、横向滚动和减少动效沿用原生行为。
`smoothScroll` 用元素本地状态绑定 `ScrollState`，兼容虚拟 List 和 GridView。
显式调用 `ListState.ScrollTo` 时，若有未完成的滚轮动画，必须同步递增传给
`smoothScroll` 的 reset 序号；仅修改行目标无法清掉框架的旧滚动动画。

常用宽度的顶部保留标题/操作、搜索/排列/筛选两行。窄窗按实际空间换行，
完整目录路径放在标题 tooltip。技能行把名称、描述、来源和操作区分开，
来源可换行，操作区保留固定宽度。

## 性能

本地列表使用虚拟化，只构建可见行和少量缓冲行；身份继续由技能状态和名称组成。
扫描先发布当前目录，其他目录计数随后更新。根目录代次、扫描序号与技能列表版本
共同阻止旧快照覆盖新目录或刚完成的操作。

`visible()` 缓存排序与搜索文本，只有集合、搜索词或筛选变化才重建结果。
同一环境下 `BenchmarkVisible` 的测量如下，单位为每次调用耗时：

| 技能数 | 稳态优化前 | 稳态优化后 | 搜索词变化前 | 搜索词变化后 |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 110 µs | 39 ns | 116 µs | 2.8 µs |
| 1,000 | 1.14 ms | 311 ns | 1.17 ms | 22 µs |
| 5,000 | 6.63 ms | 1.64 µs | 6.27 ms | 139 µs |

稳态为 0 B、0 次分配。这只测筛选函数，不代表整帧耗时。缓存以扫描生成的不可变
`Skill` 对象为基础；修改技能内容时应发布新的对象/列表，不在原指针上改元数据。

## 任务与市场

检查上下文贯穿 Git 命令和本地逐文件比较。主动取消或切换目录立即释放检查状态，
旧回调通过任务序号丢弃。已开始的安装/更新写入仍在原目录完成，沿用原来的快照
和替换流程，结果不能改变新目录状态。安装阶段由真实下载、解析、写入入口报告。

市场搜索只过滤已加载条目，支持名称与仓库，不发额外查询请求。
分页追加会使过滤缓存失效；搜索与切榜同步终止旧滚动动画并回顶部。

## 验证

- 全库测试、无 CGO 测试/构建、Go vet、MyGo vet、i18n 检查与文案迁移校验。
- 取消/安装、缓存/扫描、市场交互的 race 检查。
- 真实隔离 Linux 窗口：84 个临时技能、深浅主题、网格与列表滚轮中间帧、
  展开详情以及 940×680 窄窗；测试不接触真实技能目录。
- Windows amd64 桌面应用及 NSIS 安装包构建。Windows/macOS 的实际运行与触控板硬件手感未在云环境验证。
- Logo 两轮边缘清理候选没有改善 22/32/64 px 轮廓，保留现有资源。
